## 設計

baselineから一軸ずつ変更した。合計20件を同一A100環境でsuite記載順に実行した。

- ordinary grid: 4、6
- VV10 grid: 3、4
- density fitting: on

各候補の最大値、speedupは4件のwall time合計比である。

| grid 6 | 7.506324e-7 | 1.562552e-6 | 4.714512e-6 | 0.993x |
| VV10 grid 3 | 4.888389e-7 | 2.403511e-7 | 6.838859e-7 | 1.038x |

gridとVV10 gridの変更はこの4件では速度差がほぼなく、production設定を緩める根拠に

density-fitting近似そのものを含む。

## CPU切り分け

同じ4件のdensity-fitting設定をUjilabのPySCF 2.14.0で計算し、CPU density fittingと
GPU density fittingを同一fingerprintで比較した。PBS jobs `1440`–`1443`はすべて
exit 0で完了した。

| Job | Case | PBS wall time | Exit |
|---|---|---:|---:|
| 1440 | SiH4 | 00:02:20 | 0 |
| 1441 | SiCl4 | 00:03:48 | 0 |
| 1442 | SiH3 doublet | 00:01:48 | 0 |
| 1443 | H3Si-GeCl3 | 00:06:55 | 0 |

CPU–GPU暫定数値gateは4/4で通過した。

| CPU–GPU metric | Worst value | Case |
|---|---:|---|
| absolute energy difference | 8.732786e-8 Eh | H3Si-GeCl3 |
| gradient component RMSE | 8.061229e-8 Eh/bohr | H3Si-GeCl3 |
| gradient component max | 2.113573e-7 Eh/bohr | H3Si-GeCl3 |

directからdensity fittingへのenergy shiftはCPUとGPUでほぼ同一だった。例えば最大の
H3Si-GeCl3はCPUで`-5.501655e-5 Eh`、GPUで`-5.501599e-5 Eh`である。したがって
約5.5e-5 Ehの絶対energy shiftはGPU port誤差ではなく、density-fitting近似に由来する。

4件合計のdirect比speedupはCPUで1.958x、GPUで7.401xだった。GPU上の利得は大きいが、
production採用前に同一組成の歪み構造間でenergy shiftがどこまで相殺するかを確認する。
それまではdirect grid 5/VV10 grid 5を保守的候補として維持する。

## Relative-energy sentinel

SiH4 3歪み、SiCl4 3歪み、H3Si-GeCl3 2歪みを同一組成seedと比較した。
Ujilab PBS jobs `1444`–`1451`は8/8件exit 0で完了した。

| Metric | Result |
|---|---:|
| worst relative-energy error | 2.322385e-5 Eh |
| worst relative-energy error | 0.014573 kcal/mol |
| worst gradient component RMSE | 2.164272e-5 Eh/bohr |
| worst gradient component max | 6.451461e-5 Eh/bohr |
| aggregate CPU speedup | 1.057x |

共通の組成依存shiftは十分に相殺し、relative-energy誤差は最大0.015 kcal/mol未満だった。
gradient maxも暫定CPU–GPU gateの1e-4 Eh/bohrより小さい。gradient RMSEの最大値は
2e-5 Eh/bohrを8%だけ上回るが、これは実装parityではなくdensity-fitting近似の診断であり、
最終の科学的許容値はGate 1でfreezeする。

CPU上ではdistortion 8件の速度向上は1.06xだった一方、GPU代表4件では7.40xである。
この結果からdensity fittingをC4の条件付き候補とし、directをfallbackとして29-case
GPU ladderをSlurm job `1796282`で実行する。
